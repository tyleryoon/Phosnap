## 💡 Phosnap에 적용할 아이디어 TOP 10

### 1. ⭐ "Pay Per Photo" 하이브리드 옵션 (Shoott 착안)
**현재:** 패키지 단위 선결제만 존재
**제안:** 기본 패키지 + "추가 사진 구매" 옵션 도입
- 기본 패키지: 30분 + 편집본 20장 포함
- 추가 사진: 장당 ₩5,000~₩10,000
- 고객 심리: "일단 기본만 결제" → 갤러리 보고 추가 구매 (ARPU 상승)
**구현 난이도:** 중 (결제 로직 + 갤러리 선택 UI 필요)

### 2. ⭐ 48시간 "Express Delivery" 프리미엄 (Snapro 착안)
**현재:** 배송 기한 명시 없음
**제안:** 3단계 배송 옵션
- Standard: 5~7일 (기본)
- Express: 48시간 (+₩30,000)
- Same Day Preview: 촬영 당일 미편집 5장 선공개 (무료, SNS 공유용)
**왜 좋은가:** Same Day Preview는 고객이 즉시 인스타에 올림 → 바이럴 마케팅
**구현 난이도:** 낮 (UI + 작가 대시보드에 옵션 추가)

### 3. ⭐ AI 스타일 매칭 시스템 (업계 트렌드)
**현재:** 태그 기반 수동 필터만 존재
**제안:** "내 취향 찾기" 온보딩 퀴즈
- 5~8장의 사진 쌍을 보여주고 선호 스타일 선택
- 결과: "당신의 스타일은 Film Warm Tone" → 매칭 작가 추천
- 작가 프로필에 "스타일 DNA" 뱃지 표시
**왜 좋은가:** Flytographer도 없는 기능, 차별화 포인트
**구현 난이도:** 중~높 (퀴즈 UI + 매칭 알고리즘)

### 4. ⭐ "Moment Guarantee" — 만족 보증 제도 (Flytographer 착안)
**현재:** 환불 정책 미구현
**제안:**
- 100% 재촬영 보장 (날씨, 작가 노쇼 등)
- 70% 환불 옵션 (불만족 시)
- 작가 평점 4.5 미만 시 자동 프리미엄 배정
**왜 좋은가:** 첫 구매 허들 제거, 신뢰도 핵심
**구현 난이도:** 낮 (정책 + Terms 페이지 + 환불 플로우)

### 5. 📱 "Phosnap Stories" — 촬영 후기 피드 (UGC 전략)
**현재:** Instagram 링크만 존재
**제안:** 플랫폼 내 고객 후기 피드
- 촬영 완료 → "후기 쓰기" 유도 (포인트 적립)
- 사진 + 짧은 스토리 + 작가 태그
- 홈 화면에 "실시간 후기" 캐러셀
- 후기 작성 시 다음 예약 5% 할인
**왜 좋은가:** 참여율 6.9배 증가 (UGC 효과), 작가에게도 포트폴리오
**구현 난이도:** 중 (피드 컴포넌트 + DB 스키마)

### 6. 🌏 "글로벌 가격 표준화" 전략 (Flytographer 착안)
**현재:** 가격이 작가별 원화 기준
**제안:** 지역별 티어 시스템
- Tier 1 (서울, 도쿄, 파리): ₩200,000~
- Tier 2 (부산, 오사카, 방콕): ₩150,000~
- Tier 3 (제주, 교토 외곽): ₩120,000~
- 해외 고객에게는 USD/JPY/CNY 자동 환산 표시
**왜 좋은가:** 가격 투명성 → 예약 전환율 ↑
**구현 난이도:** 낮 (데이터 구조 + 환율 API)

### 7. 🎁 "Phosnap Gift Card" (신규)
**현재:** 선물 기능 없음
**제안:** 디지털 기프트 카드
- 금액권: ₩100,000 / ₩200,000 / ₩300,000
- 이벤트 카드: "결혼 축하 촬영권" / "생일 스냅 선물"
- 커스텀 메시지 + 브랜드 카드 디자인
- 카카오톡/LINE 공유 가능
**왜 좋은가:** 새 고객 유입 채널, 선물 시즌(크리스마스, 발렌타인) 매출 폭발
**구현 난이도:** 중 (결제 + 코드 시스템 + 공유 UI)

### 8. 📊 작가 대시보드 강화 (OurPhoto + Shoott 착안)
**현재:** ArtistSchedule 기본 구현됨
**제안:** 프로 작가 대시보드
- 수입 통계 (월별/주별 차트)
- 예약 전환율, 프로필 조회수
- 인기 시간대/장소 히트맵
- "다음 주 예상 수입" 예측
- 경쟁 작가 대비 내 포지션 (익명화)
**왜 좋은가:** 작가 리텐션 핵심, Flytographer가 작가를 잡는 이유
**구현 난이도:** 높 (차트 라이브러리 + 통계 API)

### 9. 🤝 "Duo Session" — 사진+영상 동시 예약 (차별화)
**현재:** 사진 작가만 예약 가능
**제안:** 사진작가 + 영상작가 동시 예약 패키지
- "Photo + Film Duo": 사진 50장 + 하이라이트 영상 1분
- "Full Coverage": 사진 100장 + 풀 영상 5분
- 작가끼리 "듀오 팀" 등록 가능
**왜 좋은가:** 경쟁 플랫폼 중 듀오 시스템 가진 곳 없음
**구현 난이도:** 중 (예약 플로우 확장 + 팀 매칭)

### 10. 🏷️ "Phosnap Verified" 뱃지 시스템 (Flytographer/Snapro 착안)
**현재:** 작가 선별 기준 없음
**제안:** 3단계 뱃지
- 🥉 **Verified**: 포트폴리오 심사 통과
- 🥈 **Pro**: 10건+ 완료 + 평점 4.7+
- 🥇 **Elite**: 50건+ 완료 + 평점 4.9+ + 플랫폼 추천
- Elite 작가는 홈 화면 "Featured" 노출 + 수수료 할인
**왜 좋은가:** 작가 동기부여 + 고객 신뢰 + 품질 관리 자동화
**구현 난이도:** 낮~중 (뱃지 UI + 자동 승급 로직)
