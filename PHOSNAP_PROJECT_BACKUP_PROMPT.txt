■ 알려진 패턴 & 주의사항
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. JSON 중복 키 금지 — 수정 후 항상 JSON.parse로 유효성 검사
2. CSS background-clip: text — 반드시 display: inline-block 필요
3. t() 반환값이 배열일 수 있음 — Array.isArray() 체크
4. App.jsx 전역 CSS — .nav-logo span 등이 인라인 스타일 덮어쓸 수 있음
5. 빌드 환경 — Claude 샌드박스에서 @rollup/rollup-linux-x64-gnu 없어 build 실패 (코드 문제 아님)
6. i18n 인라인 패턴 — Booking PRE_PAYMENT_NOTICE, Contact CONTENT는 {ko,en,ja,zh} 인라인 객체 패턴 (의도적)
7. ArtistRegister/ArtistSchedule — buildXxx(t) 헬퍼 패턴으로 i18n 구현 (useMemo 사용)
