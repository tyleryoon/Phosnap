LanguageContext.jsx 핵심 코드:
---
import ko from '../i18n/ko.json';
import en from '../i18n/en.json';
import ja from '../i18n/ja.json';
import zh from '../i18n/zh.json';

export const LANG_LABELS = [
  { code: 'ko', label: 'KR' },
  { code: 'en', label: 'EN' },
  { code: 'ja', label: 'JP' },
  { code: 'zh', label: 'CN' },
];

const t = (key) => {
  const keys = key.split('.');
  let val = LANGS[lang];
  for (const k of keys) { val = val?.[k]; }
  return val ?? key;  // 키 없으면 key 문자열 그대로 반환
};
---

t() 함수는 배열도 반환 가능 (예: t('booking.days') → ['일','월','화'...])
모든 페이지에서: const { lang, t } = useLanguage();

■ 알려진 패턴 & 주의사항
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. JSON 중복 키 금지
   같은 최상위 키(예: "waitlist")가 JSON 파일에 2번 나오면 나중 값이 앞 값을
   덮어씀. 수정 후 항상 node -e "JSON.parse(require('fs').readFileSync(...))"
   로 유효성 검사할 것.

2. CSS background-clip: text
   단일 글자 그라디언트 효과에는 반드시 display: inline-block 필요.
   없으면 gradient가 적용되지 않음.

3. t() 반환값이 배열일 수 있음
   t('booking.days')는 string이 아닌 string[] 반환.
   Array.isArray() 체크 후 사용 권장.

4. App.jsx 전역 CSS 주의
   .nav-logo span { color: ... } 같은 전역 선택자가
   LogoText의 인라인 스타일을 덮어쓸 수 있음. 구체성(specificity) 확인 필요.

5. 빌드 환경 제한
   Claude 샌드박스에서는 @rollup/rollup-linux-x64-gnu 모듈 없어
   npm run build 실패함 (코드 문제 아님). 로컬에서 빌드 시 정상 작동.
